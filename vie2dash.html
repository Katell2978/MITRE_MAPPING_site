🧮 Guide de Calcul du Risque (V3.0)

Pour chaque ligne et pour l'ECU global, nous appliquons une pondération basée sur la dangerosité réelle :

1. SCORE PAR LIGNE (Vulnérabilité unique) Score Ligne = CVSS_Base × 10 [× 1.1 si RCE] [× 1.2 si KEV]
  • RCE : Présence de "Remote Code Execution" dans la description.
  • KEV : Présence dans le catalogue CISA (Known Exploited Vulnerabilities).
2. SCORE GLOBAL ECU (Agrégation) Score ECU = (Max_CVSS × 7) + (Bonus_Volume)
  • Max_CVSS : La faille la plus haute définit la base (70%).
  • Bonus Volume : Gain logarithmique selon le nombre de CVE.
  • Multiplicateurs : Si l'ECU contient au moins 1 RCE (+10%) ou 1 KEV (+5%).
