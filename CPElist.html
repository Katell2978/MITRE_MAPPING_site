Gestion des vulnérabilités — tableau CPE → CVE

Cette page charge une liste de CPE et calcule, pour chacune : #CVE, #CVE avec KEV, CVSS max, date de la dernière CVE.

Données : NVD CVE API (/rest/json/cves/2.0) et catalog KEV de CISA. Conformément aux recommandations NVD : "This product uses data from the NVD API but is not endorsed or certified by the NVD."

Sources & fonctionnement

• NVD CVE API v2.0 supporte la pagination via resultsPerPage (≤ 2000) et startIndex. La réponse fournit totalResults et une liste vulnerabilities. citeturn1search37

• La clé API NVD (optionnelle) se passe dans l’en-tête HTTP apiKey. citeturn1search31

• Le catalog KEV est disponible en JSON. citeturn1search25turn1search29

⚠️ Notes pratiques : les appels NVD sont soumis à rate limiting. Le mode « Équilibré » applique des délais et limite la concurrence.

💡 Cache : les résultats sont stockés dans localStorage (par CPE + date), pour accélérer les rechargements.

🔎 Tu as déjà un prototype interne de page « Vuln by CPE » (index (4).html) — cette version se focalise sur les métriques demandées (#CVE, #KEV, CVSS max, dernière date). citeturn1search12
