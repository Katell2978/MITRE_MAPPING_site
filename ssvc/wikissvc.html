Wiki — Vehicle Vulnerability Cyber Triage (inspiré SSVC)

Mode d’emploi pour lire et utiliser la page de triage (arbre de décision).

1) Objectif

Cette page aide à déterminer une décision de traitement pour une vulnérabilité véhicule (suivi, analyse, patch…), en appliquant des règles de type SSVC (Stakeholder-Specific Vulnerability Categorization).

Le but n’est pas de “calculer un score” mais de rendre le raisonnement transparent : quelles informations sont utilisées et dans quel ordre.

2) Comment l’utiliser (pas à pas)

  • (Optionnel) Renseigner une CVE-YYYY-NNNN et cliquer Charger infos CVE pour afficher des indices (CVSS, EPSS, KEV…).
  • Choisir une valeur dans la 1ère colonne de l’arbre, puis dans la suivante, etc.
  • La zone Proposition affiche la décision suggérée et la règle associée.
  • Cliquer Appliquer la proposition pour figer la décision et l’inclure dans l’export JSON.

L’arbre est “progressif” : les colonnes apparaissent au fur et à mesure, pour éviter de demander trop d’informations d’un coup.

3) Les informations demandées (points de décision)

Les points de décision utilisés dans cette version sont :

Base_CVSS Exploitation vehicle_sa-concerned Asset_criticity System_exposure Safety_impact Technical_impact Supplier_involvement

Ces champs sont définis dans la table de décision (et certains peuvent devenir non sélectionnables si un “gating” s’applique).

4) Comment lire une décision finale ?

  • Dismiss : hors périmètre / non concerné → pas d’action de traitement dans ce contexte.
  • Track : suivre l’évolution → re-triage si de nouvelles informations apparaissent (exploitation, exposition…).
  • CyberAnalysis_required : analyse requise → besoin de réaliser une Analyse Cyber Véhicule (exposition, exploitabilité, impacts) avant de décider du traitement.
  • Defer : différer → périmètre concerné mais signal faible, revue ultérieure.
  • Patch_shedule : patch dans le cycle standard.
  • Patch_out-of-cycle : patch priorisé hors cycle.
  • Patch_immediate : patch immédiat (urgence).

5) Où sont les règles ?

En bas de la page principale, le tableau “Règles de décision (SSVC) proposées” liste toutes les règles utilisées. La première règle correspondante est appliquée.

Dans le tableau, * signifie “n’importe quelle valeur” (le critère n’est pas utilisé dans cette règle).

6) Export & traçabilité

Le bouton Export JSON produit une preuve horodatée contenant : les choix, la décision proposée/appliquée, la règle et la justification.
